# چاشنی | آشپزخانه هوشمند 🍲

یک وب‌اپ فارسی، راست‌چین و قابل نصب برای کشف دستور غذا، مدیریت مواد اولیه، ثبت دستورهای شخصی و برنامه‌ریزی هفتگی. پروژه بدون نیاز به نصب پکیج یا build اجرا می‌شود و برای انتشار مستقیم روی GitHub Pages آماده است.

## امکانات نسخه فعلی

- کتابخانه شروع با ۳۲ دستور ایرانی، بین‌المللی، فست‌فود، دسر و نوشیدنی؛ این مجموعه نقطه شروع قابل توسعه است، نه ادعای پوشش تمام غذاهای دنیا.
- جست‌وجو در نام غذا، مواد اولیه، سبک و برچسب‌ها. اعداد کالری نمونه‌ها تقریبی‌اند و جایگزین محاسبه تغذیه‌ای دقیق نیستند.
- جست‌وجوی آنلاین غذاهای بین‌المللی از API عمومی TheMealDB؛ برای این قسمت اینترنت لازم است.
- پیشنهاد غذا بر اساس مواد یخچال و وسایل آشپزی انتخاب‌شده.
- نمایش مواد لازم، مراحل پخت، زمان، تعداد نفرات، درجه سختی و نکته آشپزی.
- تغییر تعداد نفرات و محاسبه دوباره مقدار مواد عددی.
- ثبت، ویرایش و حذف دستورهای شخصی.
- علاقه‌مندی‌ها، لیست خرید قابل تیک‌زدن و برنامه غذایی هفتگی.
- ذخیره اطلاعات در `localStorage` مرورگر؛ بدون سرور و بدون ساخت حساب کاربری.
- طراحی واکنش‌گرا برای موبایل و دسکتاپ و پشتیبانی پایه از نصب به‌صورت PWA و استفاده آفلاین.

## انتشار روی GitHub Pages

1. در GitHub یک مخزن جدید بساز؛ مثلاً `chashni`.
2. همه فایل‌ها و پوشه‌های این پروژه را در ریشه مخزن آپلود کن. فایل `index.html` باید مستقیم در ریشه باشد، نه داخل یک پوشه اضافی.
3. وارد `Settings` مخزن شو.
4. از منوی سمت چپ `Pages` را باز کن.
5. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کن.
6. Branch را روی `main` و Folder را روی `/(root)` بگذار و `Save` را بزن.
7. پس از انتشار، آدرس سایت در همان صفحه Pages نمایش داده می‌شود. معمولاً قالب آدرس به شکل `https://USERNAME.github.io/REPOSITORY/` است.

## اجرای محلی

به دلیل استفاده از JavaScript Modules و Service Worker بهتر است پروژه را با یک وب‌سرور ساده اجرا کنی؛ باز کردن مستقیم `index.html` با `file://` ممکن است درست کار نکند.

با Python:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کن.

## داده‌ها و نکات مهم

- دستورهای اولیه در `js/data.js` قرار دارند. برای اضافه کردن دستورهای پیش‌فرض جدید، یک شیء با همان ساختار دستورهای موجود به آرایه `seedRecipes` اضافه کن.
- دستورهایی که کاربر از داخل اپ ثبت می‌کند و همچنین علاقه‌مندی‌ها، مواد یخچال، لیست خرید و برنامه هفتگی در مرورگر همان دستگاه ذخیره می‌شوند. پاک کردن داده‌های سایت یا عوض کردن مرورگر ممکن است این اطلاعات را حذف کند.
- جست‌وجوی آنلاین از سرویس عمومی [TheMealDB](https://www.themealdb.com/) استفاده می‌کند. این API عمدتاً غذاهای بین‌المللی دارد و نتیجه‌های آن ممکن است به زبان انگلیسی باشند.
- بخش «داغ و محبوب» در این نسخه یک مجموعه منتخب و دستی از دستورهای نمونه است؛ ادعای رتبه‌بندی زنده TikTok، Instagram یا Google Trends ندارد. برای ترند واقعی و به‌روزرسانی روزانه، باید در نسخه بعدی یک سرویس داده معتبر و ترجیحاً backend امن متصل شود. قرار دادن کلید API خصوصی در کد سمت مرورگر یا مخزن عمومی GitHub کار درستی نیست.
- عکس‌های کارت‌های نمونه از تصاویر راه دور Unsplash بارگذاری می‌شوند؛ اتصال اینترنت برای نمایش آن‌ها لازم است. در صورت ناموفق بودن بارگذاری، تصویر جایگزین محلی نمایش داده می‌شود.
- این پروژه فعلاً حساب کاربری، همگام‌سازی بین دستگاه‌ها، پنل مدیریت محتوا یا پایگاه داده مرکزی ندارد. برای این قابلیت‌ها به backend و دیتابیس نیاز است.

## توسعه‌های پیشنهادی بعدی

1. افزودن بک‌اند و حساب کاربری برای همگام‌سازی دستورها بین موبایل و کامپیوتر.
2. پنل مدیریت محتوا برای تأیید دستورها و کنترل کیفیت مواد، زمان و مراحل.
3. اتصال امن به سرویس‌های داده برای ترندهای واقعی و به‌روزرسانی‌شونده.
4. افزودن جست‌وجوی هوشمند فارسی، مترادف مواد غذایی و تشخیص مواد از روی عکس.
5. فیلتر آلرژن‌ها، رژیم غذایی، بودجه، زمان آماده‌سازی و ارزش غذایی معتبر.
